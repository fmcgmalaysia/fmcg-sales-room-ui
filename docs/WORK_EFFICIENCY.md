## Task-local working method

- State the objective, expected files, shared consumers, recovery evidence and acceptance checks before editing. Broaden only for demonstrated dependencies or new evidence.
- Reuse available content for the same path, revision and range. Reread after edits, changed live state, incomplete output or lost context. Do not substitute a stale hash for a fresh mandatory live comparison. Record a short reason for significant repetition in the existing task record; do not create a second logging system.
- Search exact paths or a known directory first. Prefer bounded excerpts. Inventory a narrow directory once when its mapping is unknown. A wider search is allowed when scoped lookup fails, but note why. Search results are not file-content reads.
- Inspect a tool error before retrying. Correct invalid quoting, wrong paths and unavailable commands; on Windows, pass a directory and rg file globs via -g. A transient external failure may justify bounded backoff. Security denials and missing login require the authorized recovery path, never an alternate bypass.
- Reuse prior command results to extract summaries. Run focused tests during development; rerun after relevant code/test changes or changed execution conditions. Preserve mandatory final gates and regression coverage for every actual shared consumer. Cross-room quantity, stock and payment logic is not a single-page-only change.
- Batch independent read-only checks sharing the same snapshot when this reduces round trips. Keep output bounded and retain errors. Do not batch dependent writes, skip intermediate confirmation, refresh dirty forms or consume a user's desktop for background work.
- For human-dependent waits, save the exact blocker, version and continuation point and request the action once. Do not repeatedly create pages. Existing approved monitoring remains unchanged until authorized otherwise. New monitoring should define an interval, bounded backoff and meaningful-change-only notifications; use event-driven resumption when available. Never abandon an authorized monitor silently.
