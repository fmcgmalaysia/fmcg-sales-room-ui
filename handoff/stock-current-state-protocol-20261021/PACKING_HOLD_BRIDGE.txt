Borrowing model changes
Now requires verified task-total evidence covering all modeled tasks. Both lender and
borrower must have zero task packing holds for approval; intentionally keeps broad
existing protection even when another source might cover a task's held cartons.
Source-specific held quantities are no longer invented/required for borrowing. Pure
dispatch helper retains existing task hold exclusion; real packing-to-dispatch integration
remains separate and must transfer holds explicitly before dispatch, not bypass them.
Receipt auto-repayment may add claims to a lender with packing holds; it never takes
away the held claims. Normal received stock and repayment continue without user action.

Receipt prototype changes
receipt-stock-reader supports either existing SOURCE_CONFIRMED or explicit TASK_TOTAL
evidence; task totals remain task totals, not copied into heldByTask source quantities.
TASK_TOTAL company/version/complete/map required. Planner checks all affected claim task
IDs/owner have nonnegative explicit totals. Positive receipts and non-reducing changes
may proceed. Implicit claim reduction with any task-total hold rejects conservatively.
With zero task hold, ordinary correction still obeys all physical balance/claim/version
guards. Explicit planner allocations remain intact; free stock can only reduce while
remaining nonnegative. Original financial/PO/cumulative receipt guards still mandatory.
This removes the former universal source-hold evidence obstacle for these cases; it
does not complete actual receipt authority adapter or cross-source borrowing mapper.
